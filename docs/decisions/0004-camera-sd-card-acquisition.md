# ADR 0004：D7100 存卡采集、导入与精确清卡

状态：已实现。本文取代已完成的迁移计划与交接提示词，描述当前契约。源码入口为 capture_profile.rs、scan.rs、task_registry.rs 与 devices/camera 的 card_capture.rs、card_import.rs。

## 采集目标与准入

新会话默认 SD。明确 Apply 并鲜读 recordingMedia=0 后采用 manifest schema 4 / profile 7；主机 RAM 须当前会话明确选择并 Apply recordingMedia=1，采用原 schema 3 / profile 6。Read、重连和其他参数 Apply 不授予主机传输许可，不隐式迁移已有任务。

正式扫描要求 D7100、单个 NEF、Live View OFF、固定摄影参数和可确认的卡策略。单卡容量足够即可；双卡只接受已证明的 Overflow，不接受 Backup。预检按存储剩余字节规划 10 暗场 + 10 空场 + N 投影，使用每张 32 MiB 的规划预算；正数剩余张数是估算，0 张卡不贡献容量，未知容量拒绝。预算不是照片文件大小上限，真实存储故障仍须安全收尾。

## 零图像载荷的拍摄事务

1. 持久化关联 session/operation 的拍摄 intent，再发送一次 InitiateCapture。
2. 等待唯一 ObjectAdded 与 CaptureComplete，严格读取 ObjectInfo，持久化含存储、名称、长度及拍摄时间的 receipt。
3. 扫描期间不下载完整图像、缩略图或部分载荷，不生成主机图像哈希；未决、重复、多余或无关联对象拒绝提交，不盲目重拍。
4. 参考组使用同一存卡事务；前暗场 10 张、前空场 10 张。空场整组连续一次开束，最后存卡回执确认后正常关束；装样后跨投影连续出束，结束不拍后参考。

L1 早释放默认开启，可在准备窗口关闭，开始时冻结该调度选项。当前拍摄先观测 D1A4 bit15 置位，再观测清零，才产生关联 EarlyExposureEnded；最多一张已接受、未完成的拍摄。非末张可据此释放匹配 CAPTURE_DONE/IDLE 并预取下一角度，下一张触发仍等前张 receipt 持久化及本位点到位。缺少早信号的该张等 receipt 后释放；不等待必达早事件、不沿用前帧证据、不在末张多走一步。未实现多张在飞的 L2 管线。

普通 MOVE 的稳定等待以固件末个脉冲下降沿起计，当前冻结契约为 150 ms；固件身份与来源进入 profile，旧设备不能冒充新时序。早释放不代替对象回执、文件校验或任务提交。

## 关束与恢复

所有开束入口共用 Moxtek adapter，已确认 OFF 后至少 2 秒才再开束。连续出束受 maxXraySec 硬限制，达到上限优先关束，未开始的投影按既定 300 秒关束间隔续办。300 秒是项目策略。空场无法在整组上限内完成则关束报错，不自动短间隔循环。

正常末张和暂停按本次可靠曝光结束关束，事务回执仍需完成。Stop、联锁、失联和未知状态优先失效安全清理。恢复鲜读冻结参数、Nano 参考及卡内元数据，唯一重绑原回执；不根据本地文件数补造已拍记录，不猜测未确认曝光。

## 安全收尾、自动导入和封存

安全收尾写 acquired / pendingImport 清单并登记 acquired_pending_import，释放采集占用但保留目录和待处理任务，禁止未验证数据重构。完整扫描流程自动进入 USB 导入，下载前再次确认 OFF。

导入由同一相机 owner 按原回执唯一重绑对象，经临时文件、长度/格式/SHA-256 校验及不覆盖提交，分别保存投影与前参考。全部通过才封存 verified 清单；缺失或变化拒绝，不覆盖原始文件。已验证本地副本可保留供恢复，导入失败时卡原件不删除。

## 只清理本次图像

全部本地文件验证并封存后再次核对长度/hash，独立 card-cleanup.json 先持久记录每项删除意图，再鲜读设备身份和 ObjectInfo，仅对本次唯一匹配对象发 DeleteObject，随后重新枚举确认消失。保留其他照片；不格式化、不删除文件夹、不使用通配或编号区间批量清理。

清卡全部确认并完成登记后才报告整个流程 Completed。失败或 Stop 保留封存本地文件、剩余卡对象和 pending registry；现有 Card import 入口跨重启续办剩余清理，不重新下载或拍摄。已删对象仅凭持久删除意图和鲜读缺失证据核销。

持久元数据先写唯一临时文件并 sync，再原子替换；Windows 错误 5/32/33 对同一替换每 20 ms 重试，最多 1 秒，可取消写入逐轮检查。失败保留旧记录并报告具体阶段，不删除旧记录、不改 ACL；删除意图未提交不得发下一条删除。
