# 原生设备控制离线候选

## 交付范围

原生 Windows WPD/PTP 相机、D7100 RAM NEF/精确参数读回、Live View 与支持的对焦、相机预设、独立设备浮层、规定方向转台规划器、异步操作、优先 Stop/OFF、独立监测、schema 3 与持久任务锁。

本次没有连接设备、打开真实串口、读取 flash、拍摄、运动、出束、烧录或修改电路。原始扫描数据保持只读。当前交付为 release/ 下唯一最新 Windows MSI 安装包，设备控制的硬件验收仍需独立完成；来源记录保存在本机证据缓存。

## 软件与数据边界

- COM 与设备 I/O 各由单一 worker 持有；主引擎处理操作结果和领域状态。JSONL v2 校验会话、请求 ID 和序号，Stop/OFF/EOF 优先，状态读取不等待长设备动作。
- `ExposureEnded` 与完整文件/哈希证据分开；末张投影和暂停按本次事件关束，事务完成仍需文件、匹配 `CAPTURE_DONE` 与提交。前空场整组连续一次开束，末张文件确认后关束；没有后参考。
- 相机采用明确设备选择、描述属性与能力。首期完整厂商适配/NEF 扫描为 D7100，其他型号只开放有证据的标准能力。无 DCC、存储卡或模拟回退。
- Live View 最多取帧 10fps，latest-only；当前用户 ACL 随机 named pipe 传递有版本、会话、序号、长度、JPEG/尺寸校验的帧，JSONL 不传图片。
- 独立单拍使用独立目录与操作文件名，不增加扫描帧数或清单。预设只存已确认相机参数；加载为草稿，明确 Apply 写入并读回，快门同步同一 Exposure 目标。
- 普通运动只沿既有负协议方向，UI 正数表示前进；限制相对 `(0,360]`、目标相位 `[0,360)`，固定 8 微步/96000 脉冲，并确认同 ticket 释放至 IDLE。HOME 内部有界反向退让保持原样。
- 未完成任务跨重启/taskId 保持锁；连接修复和只读状态可达，手动参数/对焦/运动继续锁定。受控恢复需本次明确确认 USB 自动关断释放，按冻结 V/I、Exposure、maxXraySec 和实际 profile 重建，再 HOME/哈希校验。放弃需完整清理确认，保留文件与原目录。
- schema 2 只读重构/原版本 5 合法缓存，原生 backend 拒绝追加；重构数值算法与原始 NEF 保持原样。

## 离线证据

最终机器报告和 EXE 哈希见候选包 `build-info.json`、`offline-report.json`；实际命令/退出码、完整测试结果和桌面截图保存于仓库 `.cache/` 固定分类，并在报告中定位。

前端最终门禁已验证 119 项，包含布局、菜单、真实 JSONL v2 启动 fixture、184320 种反馈组合、独立连接/手动锁、会话/帧重放拒绝和预览负方向。相机 21 项及 WPD 未知长度 EOF 状态机 4 项通过。生产协调器使用三个真实 worker 的 scripted transport 验证两轮扫描、10＋10 前参考、连续出束、末张曝光结束先关束后文件提交、同 ticket 释放和末张角度保持。

## BLOCKED：另行授权的实机验收

1. 当前 Nano flash 与候选逐字节一致性、物理方向、负载角度/回零精度、ISR 脉冲时序。现有 `stepPulseStart` 潜在共享标志竞态保持未修改、未证实。
2. D7100 本次曝光/SDRAM 对象事件语义和关联、RAM NEF、物理镜头 AF/步进、Live View、WPD 卡住时真实隔离与清理。
3. Moxtek 实测、联锁/急停、真实 OFF 写出与读回、两秒重开、温度/通信保护和连续出束上限。
4. 实机联动扫描、跨 HOME 配准、两轮角度一致性、暂停/停止与恢复。

所有 PASS 均为**仅离线验证**，设备 `hardwareCertified` 保持 false。离线 Stop 受理目标 ≤250ms；物理 OFF 确认时限需要实机证据。没有硬件认证标记或自动降级。
