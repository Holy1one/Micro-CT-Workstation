# 前端视觉层级规范

本规范适用于新增面板及后续视觉维护，本次不改变样式。实际值见 [styles.css](../../frontend/src/styles.css) 和 [tokens.css](../../frontend/src/tokens.css)，安全状态以引擎快照为准。颜色和时长一律走令牌，禁止在 `styles.css` 写十六进制颜色或毫秒字面量。

## 画布与栅格

以 1920×1080 为设计基准，铺满客户区，控件统一缩放。固定栏目不滚动，仅日志、图像条和浮层允许内部滚动。自定义标题栏高 39px；上排为相机、设备视图、射线控制器，下排为转台、日志、运行状态。上下排按 660:313 分配可用高度，间距 12px；基准下下排高 313px。工作区 padding 和列间距均为 12px。

| 列 | 内容 | 基准宽度与约束 |
|---|---|---|
| 左 | Camera / Turntable | 固定 420px，最小和最大均为 420px |
| 中 | 设备视图 / Log | `minmax(0, 1fr)`，最小 0，无独立最大值，占剩余宽度，基准约 1002px |
| 右 | 射线控制器 / Operation Status | 固定 450px，最小和最大均为 450px |

中列及子项须允许收缩（`min-width: 0`）；尺寸为设计画布坐标，显示随画布缩放。

## 排版层级

按内容职责选级，同一语义层级禁止混用两种字号；数字读数是独立层级。使用共享双语字体栈，数字使用 `font-variant-numeric: tabular-nums`。

| 层级 | 字号 / 字重 / 行高 | 判定与用途 |
|---|---|---|
| 标题 | 18px / 600 / 1.25 | 面板或窗口最高级标题 |
| 区块 | 16px / 600 / 1.25 | 面板内部的分组标题 |
| 正文 | 15px / 400 / 1.5 | 解释、操作说明和普通信息 |
| 标签 | 14px / 500 / 1.25 | 字段名、单位及紧邻控件的说明 |
| 微型 | 12px / 400 / 1.35 | 次要元数据和短辅助说明，不用于关键安全信息 |
| 数字读数 | 22px / 600 / 1.15 | 需优先识别的主读数，数字等宽；一般数值按正文层级 |

以上是新增内容的语义规格，不能按现有令牌名称直接推断：`--fontSizeHint/Label/Body/Title/Readout` 当前分别为 14/15/16/18/22px，尚无 12px 字号令牌。选用时核对实际值，缺失令牌在未来样式改动中统一补充；本次不修改字体或样式。

## 间距节奏

| 间距 | 用途 |
|---|---|
| 4px | 控件内紧邻元素、标签与字段 |
| 6px | 紧凑控件内边距或同组紧邻项 |
| 8px | 同组控件和卡片内部项的标准 gap |
| 12px | 组间、面板之间的标准 gap；面板内容标准 padding |
| 16px | 较大区块之间的分隔或宽松容器内边距 |

默认面板内容 padding 为 12px，卡片内项 gap 为 8px；工作区边缘及面板间距为 12px。既有紧凑面板存在例外；新增布局优先遵循此节奏，保证安全文案可读。

## 颜色角色

按语义选令牌并在实际背景上检查对比度。绿色只允许表示已读回确认的关束或确认状态；普通启用状态使用中性色。确认必须来自真实读回，不由点击或设定值推断。

| 语义 | 令牌 | 是否允许用于文字 |
|---|---|---|
| 选中、当前项、焦点强调 | `--accent`；焦点可用 `--focusRing` | 仅限上述强调，须满足对比度 |
| 主操作按钮填充 | `--actionFill`；按钮文字 `--onAccent` | 填充否；`--onAccent` 是 |
| 已确认的安全状态 | `--statusConfirmedText` | 是，仅限已确认状态 |
| 警告装饰底、边框 | `--warn`；文字 `--warnText` | `--warn` 否；`--warnText` 是 |
| 危险装饰底、边框 | `--danger`；文字 `--dangerText` | `--danger` 否；`--dangerText` 是 |
| 主要正文与数值 | `--textPrimary` | 是 |
| 次要解释 | `--textSecondary` | 是 |
| 非关键辅助信息 | `--textMuted` | 是，须满足对比度 |
| 普通启用及中性表面 | `--neutralSoft`；文字 `--textPrimary` | 表面否；文字是 |

`--accent` 仅用于选中、当前项和焦点强调，不能代替主操作填充或安全确认色。`--warn` / `--danger` 只作装饰底或边框，不作为正文颜色。现有部分用法尚不符合此规则，不能作为新增用法的先例。

## 动效

| 场景 | 令牌与规则 |
|---|---|
| hover / focus 控件反馈 | `--motionControl`，140ms |
| 面板展开反馈 | `--durFeedback`，180ms |
| 滚动跟随、进度 | `--durProgressFollow`，120ms，`linear` |
| 按压 | `--pressedOverlay`，10% 叠层 |

在 `prefers-reduced-motion: reduce` 下所有动效即时完成。动效不承载安全语义，状态文字和语义色必须独立可见。

## 安全文案

UNKNOWN、未确认、失联、超时和关束未确认须明确显示文字，同时使用适当的警告或危险语义色；不能只靠颜色、图标或动效。不得将未知显示为 OFF、正常或安全完成，也不得将设定值冒充实测值。绿色确认文字只用于已读回确认的关束或确认状态。

## 新增面板检查清单

- [ ] 画布、三列与上下排遵循栅格；固定栏目不滚动。
- [ ] 按内容职责选择排版层级，同层字号一致，数字使用等宽数字。
- [ ] 间距、面板 padding 与卡片 gap 遵循节奏。
- [ ] 颜色和时长使用正确语义令牌；绿色仅用于已确认状态。
- [ ] 键盘焦点清晰，选中状态不只依赖颜色。
- [ ] 文字和交互状态在实际背景、主题及强制颜色模式下具有足够对比度。
- [ ] 动效使用指定时长与缓动，减少动效时即时完成。
- [ ] 中英文文案经过 i18n 呈现边界，并检查两种语言的布局。
- [ ] UNKNOWN 和未确认同时有明确文字与语义色，状态来自引擎快照。
