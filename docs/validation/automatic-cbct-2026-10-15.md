# 自动参考校正与锥束重构（2026-10-15）

## 目标与执行清单

操作员继续使用现有 Start Reconstruction。默认单色模式自动完成：线性 CFA 配准 → 参考缺陷检测与增益修补 → 暗空场校正 → 小型缺失射线插值 → 噪声处理与负对数 → 轴校准 → 三维锥束 FDK → 验证门控的粗网格 PWLS-Huber 修正 → 自动显示窗。

1. 用空场的局部亮度与 RGB 色度比例识别异常，不固定绿背景或蓝缺陷；结合暗场和时间方差判断传感器异常。正常渐变、双色边界、长条支架、屏缘和大面积不确定区域受保护。在 12 个分散角度只核对这些参考候选位置，至少 8 个有效抽样且 80% 呈相同乘性差异时保留原实测增益，让暗空场归一化抵消固定响应；不从投影中新增缺陷区域。
2. 从相邻有效边界按通道做调和插值；修补是估计而非原始测量。保留原始无效比例门限、缺失/饱和标记及独立估计掩膜。
3. 保留 FDK 基准，验证锥束专用迭代方法；不把二维平行束 iradon 当作锥束重构。
4. 用多颜色仿真、已知真值三维体及 task5 检查；比较图使用相同窗宽。科学体保留有符号 float32，预览自动采用 P1–P99.5。

## 算法调查与本次选择

| 方法 | 三维锥束用途 | 本系统的处理 |
|---|---|---|
| FDK | 圆轨迹锥束快速解析重构；锥角较大时不完备数据仍有限制 | 保留现有 CPU/WGPU 基准、几何和滤波 |
| SIRT3D / OS-SART | 投影与反投影反复消除测量残差；子集更新可加速 | 现有 64³ SIRT 有预算限制，不冒称完整高质量后端 |
| ASD-POCS / OS-ASD-POCS / Aw-ASD-POCS | 数据一致性与 TV/自适应梯度约束，适合研究稀疏或噪声数据 | 作为后续全分辨率比较对象；强 TV 可能损失干枣细小纹理，需真值或可靠参照 |
| PWLS + Huber 保边先验 | 三维锥束前向模型、按测量方差加权、降低噪声并减轻平滑跨边缘 | 本次用 Rust 实现有界粗网格修正，无新增 Python/CUDA 运行依赖 |
| CGLS / FISTA / IRN-TV-CGLS | 最小二乘或带先验的迭代重构 | 后续需确定几何、内存、算子及参数验证后再比较 |

- [RTK 三维/二维/运动补偿 FDK](https://docs.openrtk.org/en/latest/applications/rtkfdk/README.html)。

## 实现和审计产物

- `reconstruction_defects.rs`：在 256×256 共同探测器坐标下，用三种半径的邻域中位数/MAD 判断亮度和色度离群；暗场异常及相对时间方差判断传感器异常；连通域保护与总修补预算。
- 修补范围限制在屏半径 92% 内，长宽比 >6、大区域、触边区域受保护；根据连通域大小增加不超过探测器边长 3% 的邻接光晕范围，再从外边界插值。总修补超过整图 10% 时拒绝自动修补。这些是保守工程默认值，不是已标定的检测灵敏度。
- 每通道保留原暗场/空场均值与方差，并输出 `repaired-flat.f32le`。`detector-defects.bin/json` 记录参考候选、传感器缺陷和保护区；`persistent-gain.bin` 分别记录 R/G/B 保留的实测增益位置，真正应用的逐射线估计以 `estimated-rays.bin` 为准。
- 逐投影 `estimated-rays.bin`：0 原值、1 参考增益估计、2 射线插值；质量标记 6/7 排除定量色彩覆盖，原标记 2/3/4 保留。只插值有有效边界、屏内部且不超过 16 点的缺失/饱和岛。
- 大面积同时缺失参考与投影信号的区域保持缺失，不用修补参考配合噪声下限伪造强衰减。
- `reconstruction_refine.rs`：Siddon 毫米射线路径、离散严格转置算子；64³ 粗网格、64² 探测器、最多 72 个均匀抽样视角，1/4 视角仅用于最终验证，固定 8 次拟合迭代；噪声权重用暗空场方差传播近似，平滑后的相关噪声未完全建模。
- 拟合/验证均要求实际插值后结果的粗网格均方残差下降 >2%，最大粗网格修正不超过 FDK P99–P1 范围的一半。失败保留 FDK。通过则仅将三线性粗网格差值加回原 FDK，保留其高频细节和 `fdk-baseline.f32le`。
- 缺陷、估计与迭代报告全部纳入结果 SHA-256 校验；`spectral/v3-<hash>` 不改写 v2、旧方法缓存或 NEF。
- 非标定单色执行迭代门控。多色和材料模式保持各通道共同 FDK 模型，避免给定量标定引入未经验证的非线性跨通道差别。

## 实验计划与判据

来源：academic-research-suite / experiment-agent，执行方式为现有 Rust 工程离线仿真与真实只读数据分析。计划状态随下方实测记录更新。

| 实验 | 主要判据 |
|---|---|
| 红/绿/蓝/黄色正常场和渐变 | 无误修补 |
| 不同背景上的白点、异色亮点、暗斑 | 缺陷检出，修复到同通道局部基线 |
| 正常双色边界和细长支架 | 不覆盖真实区域 |
| 暗场热像素和时间不稳定像素 | 标记传感器缺陷 |
| 固定增益差异与仅空场污染 | 前者保留实测归一化、后者修补；亮和暗两种方向均检查 |
| 平滑缺陷光晕 | 插值边界移出受污染核心，避免生成人工环 |
| 大面积参考及信号同时缺失 | 不伪造强衰减 |
| 三维椭球锥束仿真 | 毫米路径正确，A/Aᵀ 内积误差 <1e-5；独立角度残差与真实体误差下降，内部对比度保留 |
| 独立解析球体与冲突验证角度 | 一致数据的实际输出通过门控，冲突数据拒绝且原 FDK 保持逐值不变 |
| task5 新流程 | 只读原始数据，在 `.cache/tests/ct-engine/20261015-auto-cbct/` 保存新结果、掩膜、同窗切片和迭代采用/拒绝理由 |

### task5 结果

- 1643 个参考异常候选、64 个传感器异常位置、1175 个保护位置；R/G/B 分别有 14/112/7 个候选保留实测增益。候选数不等于实际修补像素数，更不是检测准确率。
- 选择绿色通道；自动水平轴修正为 1.065234375 mm，与原始 v2 应用值相同；投影方向、滤波器和物理体网格保持一致。
- 科学体为 256³ 有符号 float32，采样间隔 0.0919117647 mm；预览为 128³。默认显示窗约 [-0.059761, 0.198117]；对照图使用双方统一的 [-0.06, 0.13]，没有用不同窗口制造改进。
- 既定中央伪影区域 P99–P1 从 0.48416 降至 0.04678，仅表示该已知污染区域的极端起伏减弱，不表示成像准确率或分辨率改善了对应百分比。

- 强中央亮环、黑点和散在点状伪影明显减弱；宽环和下方移动遮挡相关伪影仍在，不能确认干枣内部结构。

## 限制

仅离线验证。参考数据无法唯一地区分紧凑支架、真实彩色结构和缺陷；缓慢大面积变化可能保留。当前不是原始 CMOS 全分辨率坏像素校准。软件不凭图像猜测散射、束硬化或材料标签，不自动拟合缺乏明确空气区域证据的亮度漂移。圆轨迹锥束不完备性、机械抖动、曝光漂移、散射、标定误差和采样限制仍可能妨碍辨认；需实物/体模对照才能评价真实分辨率和内部结构准确性。
